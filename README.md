# WalkLearn 4.0 — مشروع Android كامل

تطبيق تعلم الإنجليزية مبني بـ Python + Kivy، ومصمم ليُبنى كـ APK من GitHub Actions بدون Node.js أو npm.

## ما الموجود؟
- اختبار تحديد مستوى **تكيّفي (Adaptive)** من A1 إلى C1: 20 سؤالاً (4 لكل مستوى)، يتوقف تلقائياً عند أول مستوى لا يجتازه المستخدم، ويعرض تقريراً مفصلاً بنسبة النجاح في كل مستوى مع نصيحة مخصصة.
- دروس المنهج الأصلي للمشروع.
- 32 درس قواعد من A1 إلى C1.
- قاموس 5000 كلمة إنجليزية مترجمة للعربية عبر تنزيل أول مرة من قاموس MUSE العام، ثم يحفظه التطبيق محلياً للعمل بدون اتصال.
- كل درس يفرض على المتعلم الترتيب التالي بدون تخطي: **مفردات → حفظ → كتابة (إملاء الكلمة) → استماع (اختيار الكلمة المسموعة) → قواعد → قراءة (نص دائماً موجود، يُبنى تلقائياً من أمثلة الدرس إن لم يوجد نص جاهز) → اختبار**. بهذا الشكل كل درس يضمن تدريب: **الكتابة، القراءة، والاستماع** فعلياً وليس فقط أزرار اختيارية.
- بحث في الكلمات.
- حفظ التقدم وXP وStreak محلياً.
- أيقونة تطبيق مرفقة.
- GitHub Actions جاهز لبناء APK.

## بناء APK من الهاتف
1. ارفع الملفات إلى مستودع GitHub.
2. افتح تبويب Actions.
3. اختر **Build WalkLearn APK**.
4. اضغط **Run workflow**.
5. بعد نجاح البناء افتح الـ run ثم Artifacts وحمّل **WalkLearn-APK**.

## قاموس 5000 كلمة
القاموس الكبير ليس موضوعاً في ZIP حتى لا يصبح المشروع ضخماً ولا نضع بيانات ترجمة غير مؤكدة داخله. عند الضغط على **تنزيل 5000 كلمة مترجمة** يحتاج التطبيق إلى الإنترنت مرة واحدة. بعد نجاح التنزيل يُحفظ القاموس في مساحة التطبيق ويعمل لاحقاً دون إنترنت.

المصدر: Facebook Research MUSE ground-truth bilingual dictionaries. المشروع يذكر أن مجموعة التدريب تحتوي 5000 كلمة مصدر فريدة، مع قاموس أكبر متاح أيضاً.
